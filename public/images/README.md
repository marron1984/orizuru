# 画像の差し替えについて

このディレクトリに、以下のファイル名で画像を配置すると、サイトに反映されます。
画像が無い場合でも、各所はネイビーの単色フォールバックで崩れずに表示されます。

| ファイル名          | 用途（セクション）              | 推奨サイズ目安   |
| ------------------- | ------------------------------- | ---------------- |
| `hero.jpg`          | ヒーロー背景（フルスクリーン）  | 2400 × 1600 以上 |
| `belief.jpg`        | 信念（ステートメントの背景）    | 2000 × 1200      |
| `fold.jpg`          | ソリューション 工程: 折る       | 1200 × 900       |
| `bundle.jpg`        | ソリューション 工程: 束ねる     | 1200 × 900       |
| `deliver.jpg`       | ソリューション 工程: 届ける     | 1200 × 900       |
| `cycle.jpg`         | ソリューション 工程: 次の一巡へ | 1200 × 900       |
| `beneficiaries.jpg` | 守る順番（ステートメント横）    | 1400 × 1050      |
| `destinations.jpg`  | 届ける先（リード画像・横長）    | 2000 × 860       |
| `cta.jpg`           | CTA 背景                        | 2000 × 1200      |
| `og.jpg`            | OGP（SNS シェア画像）           | 1200 × 630       |

## 注意

- 人物・現場の写真は、実在の利用者の写真ではなくイメージ素材を用いる前提です。
  実画像を使用する際は、肖像権・同意・撤回の自由（セーフガーディング方針）に沿って
  運用してください。
- `next/image` で最適化されます。`.jpg` のほか `.webp` / `.avif` も利用できますが、
  その場合は参照パス（`content/site.ts` および各セクション）の拡張子も合わせてください。
